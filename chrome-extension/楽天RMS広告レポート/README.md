# 楽天RMS 広告レポート取り込み（Chrome拡張）

RMSの広告（RPP）パフォーマンスレポートで「この条件でダウンロード」や
「全商品レポートダウンロード」を押すと、**同じCSVをそのまま輸入管理ツールへ送る**拡張機能。
落としたファイルを探して画面から入れ直す手間が無くなる。

楽天ウェブサービスに広告のAPIは無いので、CSV以外に手がない。
こちらから勝手にレポートを作りに行くことはせず、押されたダウンロードと
同じものを1回取り直すだけにしてある。

## 入れ方

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ
   （`chrome-extension/楽天RMS広告レポート`）を選ぶ
4. RMSの広告の画面を開くと、右下に「📣 広告レポート取り込み」が出る
5. 「設定」を押して、ツールのURL（既定でOK）とサービストークン
   （Renderの環境変数 `AUTH_SERVICE_TOKEN` の値）を入れる

## 使い方

**パフォーマンスレポートの画面（`ad.rms.rakuten.co.jp/rpp/reports`）を開くだけ。**
画面のボタンを押したときとまったく同じリクエストを拡張が出して、
毎日の消化（直近3か月・日ごと）と商品ごと（今月分）を取り込む。
ファイルは保存されない。

楽天に余計な手間をかけないよう、同じ種類は6時間に1回までにしてある。
画面の選択（集計単位や期間）は書き換えないので、見ている条件はそのまま。

手で落としたいときは、いつもどおりダウンロードを押すだけ。
右下のパネルに「取り込みました：毎日の消化 29行」のように出る。
ツール側の「楽天 広告管理（RPP）」を開けば入っている。

- **毎日の消化**：集計単位「すべての広告」＋「日ごとに表示」→「この条件でダウンロード」
- **商品ごと**：「全商品レポートダウンロード」（商品別は月ごとでしか出せない）

同じ日・同じ商品は入れ替わるので、何度入れても二重にならない。

### 「前と同じ条件でもう一度」

一度ダウンロードした後は、この ボタンで**ファイルを落とさずに**同じ条件で
取り直せる。毎日の消化を追いかけるときはこれが一番早い。

### 自動を止めたいとき

「自動：入」を押すと切になる。切のときは、ダウンロードを押して受け取った
CSVも、パネルの「ツールに送る」を押すまで送らない。

## うまくいかないとき

- **右下にパネルが出ない**
  広告の画面のURLが `manifest.json` の `matches` に入っていない可能性がある。
  アドレスバーのURLを開発側に伝えれば追加する。
- **「ファイルではない応答でした」と出る**
  レポートが非同期で作られる作り（申し込んでから後でダウンロード一覧に出る）
  かもしれない。その場合はダウンロード一覧のリンクを押したときに取れる。
- **列が見つからないと言われる**
  CSVの列名が想定と違う。「状況をコピー」で内容を渡せば、
  ツール側（`backend/app/api/routes/rakuten_ads.py` の `_COLS`）に名前を足す。
