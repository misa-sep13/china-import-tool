# 楽天RMS 広告レポート取り込み（Chrome拡張）

楽天RMSの広告（RPP）の実績を、**画面を一切触らずに**輸入管理ツールへ取り込む。
ダウンロードもファイルの受け渡しも要らない。

## 入れ方

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選ぶ
4. RPPの画面（`ad.rms.rakuten.co.jp/rpp/...`）を開くと、右下に操作盤が出る
5. 「設定」→ ツールのURL（既定でOK）とサービストークン
   （Renderの環境変数 `AUTH_SERVICE_TOKEN` の値）を入れる

## 使い方

**広告の画面を開くだけ。**（右下の「今すぐ取り込む」でその場でも動く）

- **毎日の消化**（直近3か月〜昨日）… 画面と同じ検索APIから直接もらう
- **商品ごと**（今月1日〜昨日）… 全商品レポートを作らせ、出来たら受け取る

同じ種類は6時間に1回まで。「今すぐ取り込む」なら無視して動く。

## どう動いているか

画面（React）を操作するのではなく、画面が使っているのと同じAPIを呼ぶ。

| やること | 呼ぶ先 |
| --- | --- |
| 毎日の消化 | `POST /rpp/api/reports/search`（`selectionType:1`＝すべての広告、`periodType:2`＝日ごと） |
| 全商品レポートを作らせる | `POST /rpp/api/reports/downloadAsync`（`selectionType:3`＝商品別） |
| 出来上がりを見る | `GET /rpp/api/download/list`（`status:2` が完了、`reportType:13` が全商品レポート） |
| ファイルを受け取る | `GET /rpp/api/download/report?downloadId=…&reportType=…` → ZIP |

ヘッダに `X-XSRF-TOKEN`（`XSRF-TOKEN` クッキーの中身）が要る。
これが無いと403で弾かれる。

**画面の選択（集計単位・集計期間）は書き換えない。** 送る中身を変えているだけなので、
開いている画面の表示はそのまま。

### なぜ商品ごとだけCSVなのか

画面の絞り込みは「実績額 TOP10」までしか選べず、検索APIも10件しか返さない。
全商品の数字は全商品レポート（ZIP内のCSV）にしか入っていないため。

## うまくいかないとき

右下の「状況をコピー」を押すと、いまの状態と失敗した理由が入る。
「合言葉: なし」と出ていたら、RMSにログインし直す。
