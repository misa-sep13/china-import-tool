# セラースカウト（巡回する人向け）

Amazonの検索結果に出る「過去1か月で〇〇点以上購入されました」を、
登録セラーのストアフロントから集めます。**月間販売数はSP-APIでは取れず、
これでしか手に入りません。**

巡回はブラウザを自動で動かすので、**手元のPCで実行**します。
サーバー（Render）からだとAmazonに弾かれるためです。

集めた結果は一元管理のサーバーに送られ、全員が同じ一覧を見られます。

---

## 最初の1回だけ

必要なもの: **Windows ＋ Google Chrome ＋ Python**

1. Python を入れる — https://www.python.org/downloads/
   - インストール画面の **「Add python.exe to PATH」に必ずチェック**
2. コマンドプロンプトで:
   ```
   pip install playwright
   ```
   （ブラウザは手持ちのChromeを使うので、これだけでOK）

## 巡回する

```
cd scripts\scout
python sync_server.py --token <トークン> --run-by 自分の名前
```

これで **セラー一覧をサーバーから取り込む → 巡回 → 結果を送る** まで自動です。

| 付けられるもの | 意味 |
|---|---|
| `--limit 30` | 先頭30社だけ |
| `--sellers A1XXX,A2YYY` | 指定したセラーだけ |
| `--pull-only` | セラーを取り込むだけ（巡回しない） |
| `--push-only` | 前回の結果を送るだけ |

トークンは一元管理にログインしたあと、管理者に聞いてください。

## 分担について

**割り当ては決めていません。** 同じセラーを複数人が回しても、
新しい情報に上書きされるだけなので問題ありません。
むしろアクセス元が分かれるぶん、ブロックされにくくなります。

誰が巡回したかは画面に残ります（`--run-by` の名前）。

## 時間の目安

1セラーあたり約8秒、283社で**約40分**です。
速さより完走を取る作りなので、わざとゆっくり動きます。

## 気をつけること

- **Amazonにログインしたままだと自前で中止します。** 買い物用アカウントを
  巻き込まないためです。巡回用のプロファイルは自動で別に作られます
- 途中で止めても、次回は続きから再開できます
- 弾かれたら60→150→300秒と間を空けて温め直します。
  5件続けて弾かれたら、その回の走行そのものを止めます
- Amazonの規約上グレーな行為です。自己責任でお使いください

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| `認証エラー` | `--token` が正しいか。ログインし直してトークンを取り直す |
| `ローカルDBがありません` | 先に配布版のセラースカウトを一度起動する |
| 1社目から弾かれる | Amazonにログインしていないか確認。時間を空けて再挑戦 |
| 商品が0件 | そのセラーに販売数バッジが付いていない可能性 |
