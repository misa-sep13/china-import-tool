============================================================
 セラースカウト  セットアップ手順
============================================================

Amazonの検索結果に出る「過去1か月で〇〇点以上購入されました」を、
登録セラーのストアフロントから集めるツールです。

集めた結果は一元管理ツールに送られ、全員が同じ一覧を見られます。


------------------------------------------------------------
 なぜパソコンで動かすのか
------------------------------------------------------------

Amazonは、レンタルサーバーからのアクセスをすぐに遮断します。
そのため、この作業だけはご自身のパソコンで動かす必要があります。

一元管理ツールの画面でボタンを押すと、パソコン側で動く仕組みです。


------------------------------------------------------------
 【準備1】Python を入れる（最初の1回だけ）
------------------------------------------------------------

 ■ 1. 下のアドレスをブラウザのアドレス欄に貼り付けて開きます

       https://www.python.org/downloads/


 ■ 2. ページの真ん中にある黄色いボタンを押します

       ┌────────────────────────────┐
       │  Download Python 3.13.x    │  ← このボタン
       └────────────────────────────┘

       数字の部分はそのときによって変わります。
       表示されているものをそのまま押して大丈夫です。


 ■ 3. ダウンロードされたファイルをダブルクリックします

       画面の下か、右上のダウンロード一覧に出てきます。
       ファイル名は python-3.13.x-amd64.exe のような名前です。


 ■ 4. ★ここが一番大事です★

       インストール画面が開いたら、
       すぐに「Install Now」を押さないでください。

       画面の一番下に、小さなチェック欄が2つあります。

           □ Use admin privileges when installing py.exe
           □ Add python.exe to PATH      ← これにチェックを入れる

       「Add python.exe to PATH」に必ずチェックを入れてください。

       ここを飛ばすと、あとの手順が一切動きません。
       （やり直しは効きますが、入れ直しになります）


 ■ 5. チェックを入れてから「Install Now」を押します

       数分かかります。
       「Setup was successful」と出たら「Close」で閉じます。


 ■ 6. パソコンを再起動します

       これをしないと、入れたばかりのPythonが認識されないことがあります。


 ■ 7. うまく入ったか確かめます

       Windowsの検索窓（画面下の虫めがね）に

           cmd

       と入れて「コマンドプロンプト」を開き、次を打って Enter。

           python --version

       「Python 3.13.x」のように出れば成功です。

       「認識されていません」と出た場合は、
       4番のチェックが入っていません。もう一度入れ直してください。


------------------------------------------------------------
 【準備2】このフォルダを置く
------------------------------------------------------------

  zipを「すべて展開」してください。
  展開先はデスクトップが分かりやすいです。

  ★重要★
  zipの中身をダブルクリックしても動きません。
  必ず展開してから使ってください。


------------------------------------------------------------
 【準備3】ログイン情報を登録する（最初の1回だけ）
------------------------------------------------------------

  1. Chromeで一元管理ツールを開き、ログインしておく

  2. F12 キーを押す（画面の右側に開発者用の画面が出ます）

  3. 上の方にある「Console」タブをクリック

  4. 次の1行を貼り付けて Enter

         copy(localStorage.getItem('auth_token'))

     → 画面には「undefined」と出ますが、これで正常です。
        目には見えませんがコピーされています。

  5. このフォルダの【初回設定】.bat をダブルクリック

     → 初めてのときは、巡回に必要な部品の取り込みが先に走ります。
        数分かかることがあるので、そのままお待ちください。

  6. 「トークン」と聞かれたら、黒い画面の上で右クリック
     → 貼り付けられます（画面には何も表示されません）
     → Enter

  7. 「受け取った文字数: 151文字」のように表示されます。
     数字が極端に少なければ貼り付け失敗なので、4番からやり直してください。

  8. 名前を聞かれるので、ご自身の名前を入れて Enter

  「OK。セラーが 〇〇社 登録されています」と出れば成功です。


------------------------------------------------------------
 【準備4】ボタンで巡回できるようにする（最初の1回だけ）
------------------------------------------------------------

  【ボタンから起動できるようにする】.bat をダブルクリック

  一元管理ツールの「更新する」ボタンを押したときに、
  このパソコンで巡回が始まるようにWindowsへ登録します。

  ・管理者権限は要りません
  ・ご自身のログイン分だけに登録されます
  ・やめたいときは【ボタン起動を解除する】.bat で消せます

  「登録しました」と出れば完了です。


============================================================
 ここからが毎回の作業です
============================================================


------------------------------------------------------------
 ブックマークからセラーを登録する
------------------------------------------------------------

  Amazonの出品者ページ

      https://www.amazon.co.jp/sp?seller=XXXX

  をブラウザのブックマークに入れておいてください。

  1. 一元管理ツールで「競合リサーチ」→「セラースカウト」を開く

  2. 左側の「取り込むフォルダ」に、フォルダ名を入れる

     ブックマークの中の、特定のフォルダだけを取り込めます。
     フォルダ名は一部だけで大丈夫です。

         例）「Amazonセラー」と入れると
             ブックマーク バー / Ama / Amazonセラー
             の中だけを取り込みます

     空のままにすると、ブックマーク全体から探します。
     入れた内容は次回も残ります。

  3.「ブックマークを取り込む」を押す

  4. 初回だけ「Seller Scout を開きますか？」と聞かれるので
     「常に許可する」にチェックを入れて「開く」

  5. 黒い画面が開き、取り込みが始まります（数秒で終わります）

  ・Chrome / Edge / Brave / Firefox をまとめて見ます
  ・ブラウザは開いたままで大丈夫です
  ・すでに登録済みのセラーは名前だけ更新され、記録は消えません

  ※ 画面を使わず直接やりたいときは、このフォルダの
     【ブックマーク取り込み】.bat をダブルクリックしても同じです。


------------------------------------------------------------
 巡回する
------------------------------------------------------------

  ★巡回の前に、必ずAmazonからログアウトしてください★
  ログインしたままだと、途中で自動的に中止します。
  （買い物用のアカウントを巻き込まないための安全装置です）

  1. 一元管理ツールで「競合リサーチ」→「セラースカウト」を開く

  2. 左側で範囲を選ぶ
     ・最初は「登録セラー全部」ではなく、少しだけで試すのがおすすめです

  3.「更新する」を押す

  4. 初回だけ、Chromeがこう聞いてきます

        このサイトは Seller Scout を開こうとしています
        □ 常に許可する    [開く]  [キャンセル]

     →「常に許可する」にチェックを入れて「開く」

  5. 黒い画面が開き、Chromeが自動で動き始めます

  巡回中は、そのChromeのウィンドウは触らないでください。
  普段お使いのChromeとは別のものが開くので、
  ふだんのタブやログイン状態には影響しません。

  ・全289社で1時間半ほどかかります
  ・途中で閉じても、次回は続きから再開できます
  ・パソコンは使っていて構いませんが、そのまま置いておくのが確実です


------------------------------------------------------------
 気になった商品をリサーチシートへ送る
------------------------------------------------------------

  1. 巡回結果の商品カードにある「＋ リサーチシートへ」を押す
     （何件でも入れられます）

  2. 上の「競合リサーチシートに登録」を押す

  3.「競合リサーチシート」タブに切り替える

  4. 5秒ほどで「〇件を取り込みました」と出ます

  商品ごとに1件ずつリサーチが作られます。


============================================================
 うまくいかないとき
============================================================

■「python は認識されていません」と出る
   → Pythonのインストールで「Add python.exe to PATH」に
      チェックが入っていません。入れ直してください。

■「更新する」「ブックマークを取り込む」を押しても何も起きない
   → 【ボタンから起動できるようにする】.bat を実行しましたか。
   → ページを Ctrl + Shift + R で再読み込みしてみてください。

■「このトークンでは通りませんでした」と出る
   → 貼り付けが途中で切れています。
      表示された文字数を確認して、【準備3】をやり直してください。

■ 1社目から弾かれる
   → Amazonにログインしたままになっていないか確認してください。
      少し時間を空けてから、もう一度お試しください。

■ 巡回の途中で止まった
   → もう一度実行すれば続きから再開します。
      Amazonに何度も弾かれると、その回は安全のため自動で止まります。


分からないことがあれば、遠慮なくご連絡ください。
