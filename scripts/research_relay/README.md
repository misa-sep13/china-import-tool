# 取り込みサーバー（レビュー・キーワードの⚡）

競合リサーチシートの⚡ボタン（レビュー・キーワードの自動取得）は、
このサーバーが動いているPCにだけ出ます。

tool4seller にログインしたブラウザを裏で操作して取ってくるので、
ログインを預けられないサーバー（Render）には置けません。
そのため、使うPCごとにこれを動かします。

## 使い方

1. **初回だけ** `【tool4seller ログイン】.bat` を実行
   ブラウザが開くので tool4seller にログインし、ブラウザを閉じる。
   （レビューも取るなら、同じ窓で amazon.co.jp にもログイン）

2. `【取り込みサーバーを起動】.bat` を実行して、窓は開いたままにする

3. リサーチシートを開くと、レビューとキーワードに⚡が出ます

止めるときは窓を閉じてください。

## ログインが切れたら

「ログインが切れています」と出たら、1をやり直します。
7日で切れますが、切れる前に取り込めば自動で延びるので、
週に1回でも使っていればやり直しは不要です。

## 入っていないと動かないもの

    pip install playwright
    python -m playwright install chromium

## サジェストと商品画像の文字について

こちらはこのサーバーが無くても使えます（一元管理の画面から開けば、
サーバー側で処理します）。ここで持っているのはレビューとキーワードだけです。
