# 楽天への商品登録（手元のPCで実行）

一元管理で作ったドラフトを、楽天へ登録します。

## なぜ手元のPCなのか

楽天の商品APIは**書込みに有料オプションが必要**で、未契約だと401
（GA0001 Un-Authorised）になります。参照だけは申込不要です。

Compassにログインしたブラウザから内部APIへ送れば追加費用なしで登録
できますが、ブラウザが要るためサーバー（Render）では動きません。

```
サーバー : ドラフトを作る・保管する・結果を見る
    ↓ 登録待ちを取得
手元のPC : Playwright → Compass → 楽天
    ↑ 結果を送る
サーバー : status=registered にする
```

## 最初の1回だけ

```
pip install playwright
python setup.py
```

トークンと店舗URL名を保存します。Compassのパスワードは保存しません
（ブラウザに一度ログインすればCookieが残るため）。

## 登録する

```
python register.py --dry-run     # 送らずに中身だけ見る
python register.py --limit 1     # 1件だけ試す
python register.py               # 登録待ちを全部
```

ブラウザが開きます。Compassにログインしていなければ、画面でログイン
してEnterを押してください。次回からはCookieが残るので不要です。

## 1商品につき3本送ります

1本だけだと不完全な商品になるため、順に送ります。

| | 内容 |
|---|---|
| ① PUT `ext/items/manage-numbers/{番号}` | 商品本体（タイトル・説明文・価格） |
| ② POST `inventories/bulk-upsert` | 在庫（`mode` 必須） |
| ③ PUT `categories/item-mappings/...` | 店舗内カテゴリ |

①が失敗したら、その商品は止めます（在庫やカテゴリだけ入っても意味が
ないため）。

## 気をつけること

- **登録直後は楽天の検索に出ません。** 20〜30分かかります。すぐ見たい
  ときは `https://soko.rms.rakuten.co.jp/<店舗URL名>/<商品管理番号>/`
- 連続で叩くと429になるので、商品ごとに6秒あけています
- **PUTは全項目置換です。** このスクリプトは新規登録専用で、既存商品
  には使いません。既存を直すときはCompassの画面か、RMSの商品編集画面で
- 登録後もCompassの画面から編集できます（二重管理にはなりません）

## うまくいかないとき

| 症状 | 見るところ |
|---|---|
| `認証エラー` | トークンを取り直して `python setup.py` |
| 401 が返る | Compassにログインできているか。ブラウザで確認 |
| 429 が続く | 時間を空けて再実行。他の作業とぶつかっている可能性 |
| 項目が足りない | 一元管理のドラフトで、SKU・商品名・価格を埋める |
